# 自媒体 Agent 工具包 · Creator Kit

> 把自媒体运营里最费脑的三个环节，变成对 agent 说一句话。
> 现在起号的合规风险比 2023 年高了三倍，标题内卷了十倍——这些活不该占用你写内容的时间。

## 这是什么

一套给 Claude Code / 任意支持 Skills 的 agent 用的**自媒体运营技能包**。装进你的 agent 后，它就多了一个懂平台规则、懂点击心理的运营助手。

```
你：帮我检查这篇笔记能不能发
Agent：🔴 不能发。第 2 段"全网最低价"是广告法绝对化用语
      ✏️ 改为："这个价位我对比了一圈，最划算"

你：起个标题
Agent：给你 10 个候选，按点击机制排序（数字悬念/反差/身份点名…）
      ⭐ 强推：xxx，理由：xxx
```

## 免费版包含

| Skill | 干什么 | 省多少时间 |
|---|---|---|
| `content-compliance` | 发布前合规自查：广告法极限词 + 平台违禁词 + 限流风险，三层扫描，每条给改法 | 每篇 15-30 分钟 |
| `title-workshop` | 爆款标题工坊：6 大公式 + 平台修正，一次 10 个候选带排序，选完精修到发布形态 | 每篇 20 分钟起 |

## 安装（30 秒）

```bash
# Claude Code 用户：复制到技能目录
git clone https://github.com/nulloneamyourfather-droid/media-agent-kit.git
cp -r media-agent-kit/skills/* ~/.claude/skills/
```

其他支持 Skills 机制的 agent（如 ZCode 等）：把 `skills/` 下的文件夹放进对应技能目录即可。装完直接说"帮我检查这篇笔记"就能触发。
