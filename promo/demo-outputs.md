模拟输入：「帮我检查这篇笔记：姐妹们！这个面霜真的是全网最好用的面霜！我用了一个月皮肤白到发光，100%有效！需要的姐妹私信我，加微信有优惠哦～」

**输出：**

```

  ✏️ 改为："我这一个月一直在回购的面霜"
- "100%有效" → 违反：虚假承诺类（无依据的功效断言）
  ✏️ 改为："实测一个月，我的变化在图三"

- "私信我，加微信有优惠" → 风险：站外引流暗语（小红书重点打击，

  ✏️ 改为："想了解的姐妹评论区聊～"

L3 限流风险（1 处）
- "白到发光" → 提示：护肤功效夸大表述，2026 年小红书对美白类
  宣称审核加严，建议弱化
  💡 可选改法："提亮效果挺明显的"

【结论】三处硬伤必须改，尤其是"加微信"——这是封号级动作。
改完把"最好用"的部分换成你的真实使用感受，这篇反而更有说服力。
```
