# 违禁词与平台规则库

> 更新基准：2026-10。规则会变，用前可让 agent 搜最新平台规则核对。

## L1 法律红线 —— 《广告法》绝对化用语（一票否决）

出现即违规（极限词）：
最好 / 最佳 / 最优 / 最强 / 最先进 / 最便宜 / 最专业 / 最优秀 / 最高级 / 最顶级
第一 / 唯一 / 首个 / 首选 / 独家 / 独有 / 独享 / 全网第一 / 全网最低 / 全网首发
顶级 / 顶尖 / 极致 / 终极 / 王牌 / 冠军 / 销量第一 / 行业第一 / 全国第一
国家级 / 世界级 / 全球级 / 宇宙级 / 特供 / 专供（对国家的暗示）

⚠️ 历史案例中也被判违规的"隐性极限"：
「100%有效」「永久」「彻底根治」「秒杀全网」「吊打同行」「无人能超越」「前所未有」「绝无仅有」

**安全替代法**（写改法时用）：
| 违禁 | 替代 |
|---|---|
| 最好用 | 亲测好用 / 我用着顺手 |
| 全网最低 | 这个价位我找到了很划算的 |
| 第一 | 头部 / 靠前 / 排名上升 |
| 永久 | 长期有效（注明条件） |
| 100% | 大概率 / 实测数据：X 例中 X 例 |

### 虚假承诺类
包治 / 根治 / 治愈 / 药到病除 / 彻底解决 / 保证有效 / 无效退款（无依据时）/ 立竿见影

### 特殊品类自动升压
- **医疗/医美**：任何功效断言都危险（美白针、瘦脸、生发、抗衰）。改写方向：只描述体验感受，不承诺结果
- **金融/理财**：保本、稳赚、高收益无风险、躺赚、翻倍 → 违规。改写方向：讲逻辑讲风险，不承诺收益
- **教培/升学**：保过、包就业、提分承诺、押题命中率 → 违规。改写方向：讲方法讲通过率历史数据（有出处）
- **保健食品**：治疗、预防、增强免疫 → 违规（保健食品不得宣称疾病功能）

## L2 平台违禁 —— 引流暗语与行为话术

### 引流类（小红书重点打击）
加微信 / 加V / +V / VX / weixin / 卫星号 / 私聊我 / 私信领 / 扫码 / 关注公众号回复xx / 主页有惊喜 / 评论区看我主页 / 我的头像就是你想要的 / 扣1领取 / 资料在裙里（谐音"群"）/ 嘀嘀我 / 咸鱼搜xx / 某宝

**替代写法**：把"领取钩子"留在站内：用「评论区聊」「收藏慢慢看」；导流靠主页简介留痕，不在正文/评论区发联系方式

### 外链与交易类
复制链接 / 打开链接 / 点击蓝字 / 戳我 / 全网可搜xx / 去xx搜（站外平台名：淘宝、拼多多、闲鱼直接点名在部分类目违规）

### 刷量与灰色类
互赞 / 互粉 / 求关注回关 / 冲热度 / 买量 / 代发 / 帮刷

### 违禁品类暗示（出现商品关键词即升压）
药品（处方药任何形式）、烟草、电子烟、彩票、代孕、贷款中介、疏通下水道式的"特殊服务"、发票代开

## L3 限流风险 —— 低质信号与争议表述

### 低质信号词（平台判"搬运/低质"的特征）
搬运 / 抄袭他人观点不注明、大段使用「震惊」「惊呆」「99%的人不知道」等标题党套话堆叠、全文无第一人称经验（纯洗稿感）、图片文案与正文重复率过高

### 争议与边界表述
地域黑（某地人都是xx）、性别对立引战（男人都/女人都开头下判断）、炫富暗示（晒卡、报价格配轻蔑语气）、自残/极端情绪渲染（用于流量的"抑郁文学"）、明星未证实八卦当事实陈述

### 谐音与变体（平台同样识别）
「米」代钱、「yuan」代元、「薇」「ve」代微信、拼音缩写引流（klx、dfwb 等）→ 小红书风控已覆盖常见变体，变体反而触发机器复审

## 平台差异速查

| 维度 | 小红书 | 公众号 | 抖音 |
|---|---|---|---|
| 引流容忍度 | 极低（最严） | 中（可留外链白名单） | 低（评论区引流重罚） |
| 医疗健康 | 资质号才能写 | 资质号 | 资质号，违者下架 |
