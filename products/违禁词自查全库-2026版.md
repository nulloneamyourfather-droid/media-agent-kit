# 第二章 · 小红书专章 🟠

> 小红书是四大平台里**风控最严**的：违禁词限流不通知、站外引流直接处罚、变体词也能被机器识别。你的笔记"数据不好"，先查这一章。

**联系方式类**：私信我发你 / 私信领 / 私聊 / 嘀嘀我 / dd我 / 滴滴我 / 看主页 / 主页有惊喜 / 主页找我 / 评论区找我 / 头像即是 / 扫码 / 二维码 / 扫一扫 / 关注公众号回复 / 后台回复领取 / 资料在群 / 网盘发你

**⚠️ 替代策略（不是换个词，是换动作）**：

- 想导私域 → 只在**个人简介**留痕（简介的审核宽于正文），正文和评论区绝不出现
- 想卖货 → 走小红书店铺/买手带货，别在笔记里裸导流

## 2.2 低质与搬运信号 🟡（限流重灾区）

- 全文无第一人称经验、纯资料堆砌（机器判"搬运"）
- 多篇笔记互相重复率高
- 标题党堆叠：震惊 / 惊呆 / 99%的人不知道 / 删前快看 / 速看 / 马上删 / 转疯了
- 图片文案与正文一字不差
- 深夜批量发布、频率异常（行为风控）

## 2.3 争议性内容 🟡

- 性别对立：男人都 / 女人都 / 国男 / 国女 / 拜金女 / 直男癌 / 渣男都这样
- 地域标签：某地人都 / X省X市+贬义判断
- 炫富挑衅：晒存款配轻蔑文案 / "月薪3千不配xx"
- 极端情绪引流：抑郁文学 / 自残暗示 / "活不下去了"配带货
- 明星八卦当事实：未经证实的恋情/塌房表述

## 2.4 小红书高频误伤词 🟠（真人人发的也会被判）

- 「**减肥**」→ 美白/瘦身/减脂宣称收紧，改「体态管理」「轻断食记录」
- 「**最便宜**」类比价词 → 见第一章
- 「**治愈**」非医疗语境也慎用（"治愈系"在部分类目触发医疗审核）
- 「**赚钱**」→ 副业/搞钱类目，"躺赚""睡后收入"必限流；"月入x万"需收入凭证，否则改"做到过"
- 「**ChatGPT/翻墙/VPN**」→ 违规服务类词，直接处理

# 第四章 · 公众号/微信生态专章 🟠

> 公众号对极限词同样严（《广告法》执法主战场），但对站外链接相对宽容（白名单机制）。真正的坑是**诱导分享**和**虚拟支付**。

## 4.1 诱导分享 🔴

- 不转发不看全 / 转发后截图领取 / 分享到朋友圈解锁 / 邀请x人助力（无资质的裂变）
- 「不转不是中国人」类道德绑架（直接封）

## 4.2 虚拟支付 🟠（iOS 端）

- iOS 内购买虚拟内容（课程/会员）绕过苹果支付 → 文章被删/功能封禁
- 二维码引导 iOS 用户微信转账购买虚拟服务 → 高危

## 4.3 标题党 🟡

- 「刚刚，xx宣布」「重磅」无实质 / 标题与内容严重不符 / 名人亲属+隐私暗示

# 第六章 · 替代写法速查总表（100+ 条精选）

> 左边是违规/高危词，右边是实测能过审且转化不降的表达。**用"真实感"替代"夸张感"**——2026 年的算法和用户都吃真实感。

| 高危写法 | 安全替代 |
|---|---|
| 全网最低价 | 这个价位我对比了一圈，它最划算（注："最"限内比不比外）→ 更稳：这个价位我目前找到最合适的 |
| 最好用 | 我用过这么多款里，它留到了最后 |
| 100%有效 | 实测 X 例里 X 例有变化（给数据）|
| 永久有效 | 长期有效（页面标注条件）|
| 第一名 | 近期排名上升很快 / 头部选手 |
| 销量冠军 | 卖爆了 / 补货三次 |
| 秒杀全网 | 同价位我没见过更好的 |
| 顶级配置 | 配置拉满 |
| 独家 | 目前只在这么几家见得到 |
| 国家级认证 | 有xx认证（写具体证书名）|
| 治好 / 根治 | 我的使用感受是xx改善了 |
| 7天见效 | 我第 7 天的变化（晒图）|
| 保过 | 往届通过率（真实数据）|
| 稳赚 | 我的实际记录（晒收益+标注风险）|
| 睡后收入 | 有持续进账的副业尝试 |
| 加微信领资料 | 评论区扣1 / 收藏防走丢 |
| 私信我 | 「评论区聊聊」（站内互动）|
| 震惊体 | 直接说反差事实：xx价格砍到xx |
| 99%的人不知道 | 我身边 10 个人 9 个不知道 |
| 无脑冲 | 闭眼入的前提是……（带条件）|
| 平替 | 同风格 / 类似版型 |
| 医美级 | 上脸有紧致感（体验描述）|
| 治便秘 | 膳食纤维含量高（成分描述）|
| 降血压 | 适合控盐人群的口粮（人群描述）|
| 月入5万秘密 | 我这三个月的副业流水（凭证图）|

**核心公式：把「断言」改成「记录」，把「承诺」改成「体验」，把「绝对」改成「数据」。**
